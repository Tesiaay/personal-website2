# AI Resume Website UI 设计文档

> 资料来源：`docs/resume-prd.md`、`image/设计参考/second第二版网页颜色字体.md`、`image/设计参考` 截图与 IP 形象。  
> 原始参考网页：https://www.newvalleylabs.com/?ref=onepagelove#team  
> 说明：原始网页可访问到 about、team、portfolio、contact 等文本结构，但具体视觉细节以本地截图为主要依据。

## 设计定位

这是一个面向招聘方和面试官的个人 AI 产品经理作品集网站。整体不做传统商务简历风，也不做冷科技风，而是做成“复古海报感 + 手绘 IP + 清晰简历信息”的个人品牌页面。

设计关键词：

- 温暖、有记忆点、轻复古
- 奶油米色背景，深巧克力棕文字
- 大标题厚重、圆钝、有海报冲击力
- 手绘蝴蝶 IP 作为人格化视觉资产
- 内容仍然要清楚、可扫读，不能因为趣味视觉影响招聘阅读效率

推荐设计参数：

- `DESIGN_VARIANCE: 7`，保留非对称、插画和大标题带来的个性
- `MOTION_INTENSITY: 5`，使用滚动入场、按钮触感、轻微漂浮，不做复杂炫技动画
- `VISUAL_DENSITY: 4`，信息足够完整，但每屏保留大留白和清晰层级

# 第一部分：视觉风格规范

## 1. 配色方案

### 主色板

| 角色 | 色名 | 色号 | 用途 |
| --- | --- | --- | --- |
| 页面背景 | 奶油米色 | `#E7DFC2` | 全站主背景、大标题填充色、卡片浅底 |
| 主文字 / 描边 | 深巧克力棕 | `#4B271C` | 标题、正文、边框、IP 外轮廓、按钮文字 |
| 主强调色 | 复古橙 | `#E15732` | CTA、标题阴影、重点词、激活态 |
| 第二强调色 | 蓝绿色 | `#4FA7A7` | 次按钮、模块标题、图标、关键节点 |
| 辅助色 | 橄榄绿 | `#AAB35A` | 标签、植物装饰、能力模块点缀 |
| 趣味点缀 | 柔和粉 | `#E7A7A9` | IP 肤色、推荐语、轻情绪化装饰 |
| 辅助亮黄 | 花心黄 | `#F6C431` | 少量图形和高亮，不作为正文色 |

### 使用规则

- 全站以 `#E7DFC2` 作为统一底色，不在不同板块频繁切换深浅主题。
- `#4B271C` 是视觉锚点，所有文字、线框、描边优先用它，保证复古感和阅读稳定性。
- `#E15732` 只承担强行动和强强调：主 CTA、标题投影、关键数字、当前状态。
- `#4FA7A7` 用于辅助层级，适合次按钮、流程节点、项目编号、图标背景。
- `#AAB35A` 和 `#E7A7A9` 只做轻点缀，不要大面积铺底，避免页面变成儿童插画风。
- 避免额外引入紫色、冷灰、科技蓝、黑色渐变。AI 主题通过内容和流程图表达，不通过“AI 紫蓝渐变”表达。

### 背景纹理

参考截图中有明显半调网点背景。实现时建议用 CSS 背景叠加：

```css
background-color: #E7DFC2;
background-image: radial-gradient(rgba(75, 39, 28, 0.16) 1px, transparent 1px);
background-size: 8px 8px;
```

使用限制：

- Hero、Contact、章节过渡页可以使用半调网点。
- 正文密集区域降低网点透明度到 `0.06-0.08`，避免影响中文阅读。
- 卡片内部不使用高对比网点，保持纸面阅读感。

## 2. 字体规范

### 字体变量

```css
:root {
  --font-display-cn: "DeyiHei", "得意黑", "YouSheBiaoTiHei", "阿里妈妈数黑体", "Noto Sans SC", sans-serif;
  --font-display-en-strong: "Bungee", "Anton", "Impact", sans-serif;
  --font-display-en-clean: "Anton", "Bebas Neue", "Impact", sans-serif;
  --font-body: "Noto Sans SC", "Source Han Sans SC", "PingFang SC", "Microsoft YaHei", sans-serif;
}
```

### 字体层级

| 类型 | 字号 | 行高 | 字重 | 用途 |
| --- | --- | --- | --- | --- |
| 英文 Hero 大标题 | `clamp(64px, 7.5vw, 128px)` | `0.88` | `900` | `AI PRODUCT`、`WORKFLOW BUILDER` |
| 中文 Hero 标题 | `clamp(44px, 5.8vw, 88px)` | `1.05` | `900` | 姓名、中文定位 |
| 页面一级标题 | `clamp(52px, 6vw, 104px)` | `0.95` | `900` | ABOUT、PROJECTS、CONTACT |
| 模块标题 | `clamp(22px, 2.2vw, 34px)` | `1.1` | `800` | 项目标题、能力标题 |
| 小标签 | `14px` | `1.3` | `800` | PROJECT 01、WHAT I DO |
| 正文 | `16px` | `1.7` | `400` | 介绍、项目说明、经历描述 |
| 重点说明 | `18-22px` | `1.6` | `500` | Hero 副文案、About 摘要 |
| 按钮文字 | `14-15px` | `1` | `800` | CTA、导航按钮 |

### 大标题立体字规则

只在 Hero 和页面一级标题使用。

```css
.display-title {
  color: #E7DFC2;
  -webkit-text-stroke: 2px #4B271C;
  text-shadow: 8px 8px 0 #E15732;
}
```

注意：

- 中文标题使用立体字时，字号不要超过英文标题。
- 正文、按钮、标签不使用立体字。
- 同一屏最多一个立体标题，避免视觉噪音。

## 3. 圆角、阴影、边框和卡片

### 圆角系统

| 组件 | 圆角 |
| --- | --- |
| 主按钮 / 次按钮 | `999px` 胶囊 |
| 普通信息卡 | `18px` |
| 项目大卡 / 图文面板 | `28px` |
| 小标签 | `999px` |
| 图片裁切 | 优先使用花瓣形、圆形、软圆矩形，不用锐利直角 |
| 浮动返回顶部按钮 | `50%` |

### 边框

- 主边框：`2px solid #4B271C`
- 次边框：`1px solid rgba(75, 39, 28, 0.25)`
- 手绘风边框可以使用 `border-radius` 不规则组合，但不要影响内容对齐。

### 阴影

复古海报风不使用现代玻璃阴影，优先使用硬投影。

```css
.hard-shadow {
  box-shadow: 8px 8px 0 #4B271C;
}

.orange-shadow {
  box-shadow: 8px 8px 0 #E15732;
}
```

使用规则：

- 主 CTA 使用橙色底或橙色硬投影。
- 卡片使用深棕硬投影，hover 时投影缩短并轻微位移，模拟按压。
- 正文卡片阴影不要过多，避免信息区太重。

### 卡片样式

卡片不是全站默认容器，只用于项目、能力、推荐语等需要分组的信息。

推荐卡片：

- 背景：`rgba(255, 248, 220, 0.45)` 或 `#E7DFC2`
- 边框：`2px solid #4B271C`
- 圆角：`18px` 或 `28px`
- 内距：桌面 `28-40px`，移动端 `20-24px`
- hover：`transform: translate(-2px, -2px)`，阴影从 `6px 6px 0` 变 `10px 10px 0`

## 4. 图形和 IP 使用

### IP 形象

`image/设计参考/IP形象.png` 是主 IP：蝴蝶、蓝绿色翅膀、粉色身体、深棕描边。它应该作为个人品牌记忆点，而不是每个区块都重复的大装饰。

使用建议：

- Hero：作为主视觉，放在右侧或底部偏右，可以有轻微漂浮。
- About：缩小成旁白角色，像“引导者”一样出现在内容旁。
- Contact：再次出现，作为收尾和联系引导。
- 其他区块：只使用局部元素，如翅膀色块、小星星、小叶子，不重复完整大图。

### 花朵和手绘形状

参考截图中大量使用花朵、花瓣裁切、半调网点。简历网站中可转化为：

- 项目卡片的编号徽章用花心圆形。
- 推荐语头像或引用卡使用花瓣形裁切。
- Skill 标签前使用小花 icon 或圆点。
- 页面过渡处用大花朵半露出视口，不要居中堆满。

### 整体协调性

- 页面基调是“温暖可信”，不是“可爱玩具”。招聘信息必须始终保持可读。
- 每屏最多使用一个大型装饰主体：IP、花朵、项目截图、流程图四选一。
- 标题可以强烈，正文必须克制。
- 所有图形描边统一深棕，避免黑色线条和深棕混用。
- 交互可以有趣，但不要让用户猜功能。按钮、链接、下载入口必须清晰。

### 目标

让招聘方在第一屏确认：她是谁、目标岗位是什么、为什么值得继续看、可以下载简历或联系。

- 主标题：`AI Product Manager / Agent Workflow Builder`
- 中文定位：AI 产品经理候选人 / AI 产品实践者
- 副文案：从业务执行、需求转化到 AI 产品实践，正在用真实项目完成 AI 产品经理转型。
- CTA：查看项目、下载简历、联系我
- 基础信息：南京 / 上海、一周内到岗、邮箱

### 布局

- 桌面端：左右非对称布局。
  - 左侧：超大英文海报标题 + 中文定位 + CTA。
  - 右侧：蝴蝶 IP，大图但不遮挡标题。
  - 顶部：小型文字 Logo 或姓名缩写，导航靠右。
  - 右上角：保留已有 `Download Resume / 下载简历` 按钮。
- 移动端：标题在上，IP 在中，CTA 在下，下载按钮进入正常内容流。

### 组件

- `HeroTitle`：复古立体字标题
- `HeroMetaBar`：城市、到岗、邮箱
- `PrimaryButton`：查看项目
- `SecondaryButton`：联系我
- `DownloadButton`：下载 PDF 简历
- `MascotStage`：IP 主视觉容器

### 交互

- 标题入场：轻微上移 + 透明度渐显。
- IP：`translateY(-6px)` 到 `translateY(6px)` 的慢速漂浮。
- CTA hover：硬投影变大，按钮上移 `-2px`。
- 下载按钮 hover：橙色强化，鼠标变为 pointer，保持明显可点击。
- 支持 `prefers-reduced-motion`，关闭漂浮，仅保留 hover 状态。

- 右侧或下方：Memory 机制流程线。

### 组件

- `WorkflowGrid`
- `WorkflowCard`
- `MemoryFlow`
- `PromptCompare`
- `ResultStamp`

### 样式

- 任务入口卡用不同小色块区分：
  - TASK：复古橙
  - KNOWLEDGE：蓝绿色
  - DECISION：橄榄绿
  - REFLECTION：柔和粉

- 流程线用手绘虚线，不用冷冰冰的节点图。

### 交互

- Memory 流程进入视口时节点依次点亮。
- Prompt 对比卡可用 tab 或 segmented control 切换“优化前 / 优化后”。
- 移动端默认展开核心结果，不隐藏关键信息。

# 全站交互规范

## 导航

- 桌面端导航固定顶部或吸顶，背景保持透明或奶油米半透明。
- 导航项：About、Projects、Experience、Contact。
- 当前锚点用复古橙下划线或小圆点标记。
- 移动端使用简洁菜单，不做复杂全屏动画。

## 动效

推荐动效：

- Section 进入视口：`opacity 0 → 1`，`translateY(24px) → 0`
- 大标题：轻微错位入场，模拟海报字落位
- 卡片 hover：硬投影变化
- IP：慢速漂浮
- 流程线：节点依次点亮

禁止动效：

- 大面积 3D 旋转
- 闪烁霓虹
- 高频循环抖动
- 自动播放视频式背景
- 影响正文阅读的逐字动画

## 响应式

| 断点 | 规则 |
| --- | --- |
| `>= 1200px` | 最大内容宽度 `1180-1280px`，允许装饰图形超出 |
| `768-1199px` | 双栏变窄，标题缩小，图形不遮挡正文 |
| `< 768px` | 所有区块单列，项目卡和时间线纵向 |
| `< 420px` | CTA 允许上下堆叠，按钮宽度 `100%` |

## 可访问性

- 正文最小 `16px`，中文正文行高不低于 `1.65`。
- 所有按钮必须有清晰 hover 和 focus-visible。
- 橙色按钮上的文字优先用深棕，不用白字，保证复古感和对比度。
- IP 和装饰图如果无信息意义，`alt=""`。
- 项目截图、流程图必须有准确 alt。
- 所有链接在 PDF 和网页中都应保留真实 URL 或可点击行为。

## 实施优先级

1. 先建立颜色、字体、按钮、卡片、标题组件。
2. 再完成 Hero、Project Index、About 三个决定首屏印象的区块。
3. 然后实现 Tiva 和 AI Resume Website 两个项目详情。
4. 最后补齐 Experience、Testimonials、Contact 和返回顶部。
5. 每完成一个区块都检查移动端，避免大标题和 IP 遮挡内容。
